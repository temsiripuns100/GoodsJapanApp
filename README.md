# Goods Japan (กูดส์ เจแปน)

เว็บไซต์ร้านของมือสองญี่ปุ่น ปั๊ม ปตท. คลอง 4 ข้าง Café Amazon ปทุมธานี
ติดตั้งเป็นแอปบนมือถือได้ (PWA)

## ติดตั้งเป็นแอป
- **Android (Chrome):** เปิดเว็บ แล้วกดแถบ "ติดตั้ง" ด้านล่างจอ หรือเมนู ⋮ → ติดตั้งแอป
- **iPhone (Safari):** กดปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม

## แก้ไขเว็บ
หลังแก้ไฟล์ใดๆ ให้เปลี่ยนค่า `VERSION` ใน `sw.js` เพื่อให้เครื่องที่ติดตั้งแอปไว้โหลดของใหม่
